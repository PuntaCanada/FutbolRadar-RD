# National history

Upstream: https://github.com/martj42/international_results (CC0-1.0). Import resolves a commit SHA once, fetches results.csv, shootouts.csv and LICENSE at that exact revision, checks SPDX metadata, validates scores, dates, neutral flags, duplicate keys and shootout associations, and records SHA-256 hashes. Set NATIONAL_UPSTREAM_SHA to replay a specific revision. CI retains the generated data/national.json artifact. Before merging, commit that validated snapshot to this branch and rerun CI against the pinned revision; Cloudflare build is offline and does not fetch upstream. Until that snapshot is committed, the public build keeps the existing empty-data fallback. Source catalog publish flags remain off pending review. Scores include extra time and exclude shootout goals; shootout wins/losses are separate and tied scores remain draws. Historical completeness is not guaranteed. No active sponsorship or affiliate links.
